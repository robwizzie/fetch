# Audio credits

Every recorded sound and track in `assets/audio/` is **CC0 1.0 (public domain dedication)**.
Nothing here is CC-BY, CC-BY-SA or NC: each source page below was checked for an explicit CC0 license
before its file was used. Credit is not required by CC0; it is listed so the provenance is auditable.

Takes from Freesound were cut from the public HQ previews, trimmed to a single bark/hit, faded,
folded to mono, level-matched and re-encoded to Ogg Vorbis. File names carry the Freesound sound ID
(`fs<ID>.ogg`, `_n` for the n-th take cut from one recording).

## Music — Komiku / Loyalty Freak Music (CC0)

From the album *Poupi's incredible adventures!* on OpenGameArt: https://opengameart.org/content/poupis-incredible-adventures-full-album
(author: [loyalty-freak-music](https://opengameart.org/users/loyalty-freak-music), license: CC0). Decoded from the published MP3s
and re-encoded to Ogg Vorbis, otherwise untouched; each track's length is a whole number of bars, so it loops on the bar.

| File | Use | Track |
|---|---|---|
| `music/menu.ogg` | menus (`Music.play("menu")`) | 06 Fetch Land (120 bpm, 64 s) |
